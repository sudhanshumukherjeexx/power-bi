# Ownership matrix (RACI)

**Use it** for definitions, models and processes that more than one team touches. **Readers:** everyone named in it.

## Template

```markdown
| Item | Responsible (does the work) | Accountable (decides, one person) | Consulted | Informed |
|------|-----------------------------|-----------------------------------|-----------|----------|
| <KPI definition> | | | | |
| <Semantic model> | | | | |
| <Process: certification, release, retirement> | | | | |
```

## Rules of thumb

- Exactly one Accountable per row, and it is a person, not a team.
- Business definitions are accountable to the business (CFO for ledger revenue); models are accountable to the BI lead.
- If nobody wants to be Accountable, ask whether the item is needed at all.

## What good looks like

- [ ] Every certified model and company KPI has a row.
- [ ] Names, not "Finance" or "IT".
- [ ] Reviewed when people change roles.
