# Power BI Holy Grail

A free, hands-on path from Power BI beginner to 5-year senior.

**Start here: [sudhanshumukherjeexx.github.io/power-bi](https://sudhanshumukherjeexx.github.io/power-bi/)**

## What's inside

- **73 hands-on assignments** across Beginner, Intermediate and Advanced. Each one has a checkable expected result and a worked solution.
- **188 interview flashcards** in plain English, with spaced repetition and a timed mock interview. You don't need Power BI to use them.
- **90 interview questions and 68 assessment items**, grouped by topic.
- **Glossary** of 139 Power BI terms, explained without jargon.
- **Printable cheat sheets** for each level.
- **Career paths** (Data Analyst, BI Developer, Analytics Engineer, BI Lead) and a **certification map** for PL-300 and DP-600.
- **14 practice datasets** from one fictional company, Northwind Outdoors, in the [`data`](data) folder.
- **A starter Power BI project** with the clean tables already loaded and related: [`starter/northwind-starter.zip`](starter/northwind-starter.zip).

## How to use it

1. Open the site and pick a level, or choose a career path to see which topics matter for that job.
2. Download or copy a dataset, then do the assignment in Power BI Desktop (free).
3. Compare your work with the expected result. Open the worked solution if you get stuck.
4. Study the flashcards whenever you're away from your computer.

The site works on phones, iPhone and iPad. You can add it to your home screen and use it offline. Your progress is saved in your browser, and **Export / Import progress** moves it between devices.

## Tools you'll need

- [Power BI Desktop](https://www.microsoft.com/power-platform/products/power-bi/desktop) (free)
- A free Power BI account, for the Service topics
- [DAX Studio](https://daxstudio.org) and [Tabular Editor 2](https://github.com/TabularEditor/TabularEditor) (both free), from Intermediate onward
- A Microsoft Fabric trial, for the last Advanced topics

---

Northwind Outdoors is a fictional company. All data is synthetic.
