Why the business cares Most BI work is changing systems that are already in use. Every change moves numbers people have already seen; doing it without impact analysis is how trust is lost.

ETElena TorresBI Lead (your manager)email Mon 20 Apr, 09:00

Four CRs for the sales model

  • CR1 (Sarah): returns should reduce revenue in the month the return is received, not the month of the original order.
  • CR2 (Sarah): shipping refunds should also reduce revenue.
  • CR3 (Ava): contractors in Europe must not see employee salary data.
  • CR4 (Sarah): from FY2026 Finance reports on a 4-4-5 calendar starting Sunday 28 Dec 2025.

For each one: what changes, by how much for Q1 2026, what could break, and how you'll test it. Then implement them.

What you are expected to do

  • Write an impact assessment per CR: what changes, the Q1 2026 effect in dollars, what else could break, how you'll test it.
  • Implement the four CRs as separate, reviewable changes.
  • Run a regression check on everything the CRs should not affect.

Deliverables

  • Impact assessment per change request
  • Implemented changes (DAX, model, roles, calendar table)
  • Regression results

Evidence

  • order_lines.csv
  • orders.csv
  • returns.csv
  • employees.csv
  • Current dashboard values, Q1 2026
