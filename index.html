    Starter Power BI project

    Want to skip ahead to DAX? This Power BI project has 12 clean tables loaded, typed and related in a star schema, with DimDate marked as the date table. The Beginner modeling topic asks you to build this model yourself, so use the starter only to skip ahead. RawOrdersExport and SurveyWide aren't included: cleaning them is part of the Power Query topics.

    Datasets

    One coherent fictional company, Northwind Outdoors, sells outdoor gear across four regions. All tables join to each other, so any assignment can grow into a full model. Every table is 100 rows or fewer. Use Copy CSV then paste into Excel (save as .csv) or straight into Power BI Desktop via Get Data → Enter Data → paste.

    Every table is also saved as a CSV file in this project's data/ folder. Use Download .csv on any table, or point Power BI at the whole folder with Get Data → Folder. Because the files are online, Get Data → Web with a file's address also works, and it refreshes in the Service without a gateway.

    Northwind Outdoors is a fictional company. All figures are synthetic and generated deterministically so everyone working from this page sees identical numbers, which is what makes the expected results checkable.
